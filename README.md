## 📌 Project Overview

This project presents an interactive **Blinkit Sales Performance Dashboard built using Microsoft Power BI**.

The dashboard transforms raw sales data into meaningful business insights using data cleaning, transformation, data modeling, DAX, and interactive visualizations.

## 🎯 Objectives

* Analyze overall sales performance
* Compare outlet performance
* Analyze product and item categories
* Understand outlet size and outlet-type performance
* Analyze customer ratings
* Identify sales patterns and trends
* Present insights through an interactive dashboard

## 🛠️ Tools & Technologies
